# 🚗 DVLA Vehicle Management System

This is a fully functional and beautifully designed website built for the **Driver and Vehicle Licensing Authority (DVLA)** to help automate and simplify vehicle license renewal and customer management.

---

## 📌 Project Description

The DVLA Vehicle Management System is designed to streamline operations at DVLA offices by allowing staff to:

- Log in securely as administrators
- Add and manage vehicle owner information
- Track license expiry dates
- Send alerts to notify customers before their license expires

It combines functionality and modern design to ensure users enjoy a seamless experience while accessing or managing information.

---

## 🎯 Features

- **Homepage** with dynamic scrolling, welcome banner, and animated sections
- **Admin Login Page** with form validation and redirection to dashboard
- **Admin Dashboard** to manage customer records
- **Add Customer Page** for storing vehicle information
- **Gallery, Services, About & Contact Sections**
- **Modern Responsive Design** using HTML, CSS, and JavaScript
- **Local Storage** to save and manage data (can be upgraded to a backend system)

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3 (Flexbox + Grid)**
- **Vanilla JavaScript**
- **Font: Poppins from Google Fonts**
- **Image-based backgrounds and effects**
- **No backend required (data saved locally in browser)**
